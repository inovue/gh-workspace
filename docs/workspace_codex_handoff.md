# Historical Workspace Launcher Handoff

This file originally described the pre-implementation product exploration for `gh-workspace`. It is retained only to explain the project's origin and is not a current specification.

The original proposal explored a full-screen launcher that merged local and remote repositories, launched editors and shells, supported configurable scan roots, and cached repository metadata. The implemented product deliberately became a smaller command-first GitHub CLI extension.

Use these documents as the current sources of truth:

- [`CONTEXT.md`](../CONTEXT.md) for domain language
- [`docs/mvp-spec.md`](./mvp-spec.md) for current behavior
- [`docs/adr/`](./adr/) for architectural decisions
- the code and tests when documentation and implementation disagree
